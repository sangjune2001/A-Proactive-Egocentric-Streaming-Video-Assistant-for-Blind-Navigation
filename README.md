# Rule-based Trigger

시각장애인 보행 보조 시스템의 위험 상황 감지 코드입니다.
학습된 `best.pt`와 영상을 업로드하면 YOLO 검출, BYTETrack 추적, 규칙 기반 Trigger를 순서대로 실행합니다.
최종 선택한 규칙과 하이퍼파라미터가 적용되어 있습니다.

## 감지 대상

- 차량·자전거·킥보드 및 장애물·계단 접근
- 차량류의 급진입
- 신호등의 빨간불 ↔ 초록불 변화

## 실행 방법

1. `rule_trigger_upload.ipynb`를 Google Colab에서 엽니다.
2. **런타임 → 모두 실행**을 선택합니다.
3. 첫 번째 업로드 창에서 `best.pt`, 두 번째 창에서 분석할 영상을 선택합니다. 영상은 여러 개를 선택할 수 있습니다.
4. 분석이 끝나면 결과 영상과 Trigger 로그가 담긴 ZIP 파일이 다운로드됩니다.

## VLM 연동

기존에 사용하던 임시 Trigger를 이 코드로 교체합니다.
노트북의 **3번 ‘팀의 기존 VLM 함수 연결’** 셀에서 기존 VLM 호출 코드를 연결하고 `VLM_CALLBACK`에 등록합니다.

Trigger가 발생하면 이벤트 정보, 현재 프레임, 최근 약 2초의 프레임 목록이 전달됩니다.
VLM과 TTS는 팀의 기존 코드를 연결해 사용합니다.
