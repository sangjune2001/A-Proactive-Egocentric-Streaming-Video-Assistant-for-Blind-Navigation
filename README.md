# Trigger 실행 안내

사용 파일: `rule_trigger_upload.ipynb`

**`best.pt`와 영상만 업로드하면 객체 검출·추적·위험 판단이 자동으로 실행됩니다.** 프레임이나 검출 결과를 직접 입력할 필요가 없습니다. 확정한 규칙과 하이퍼파라미터는 그대로 들어 있습니다.

## 사용 방법

1. Colab에서 노트북을 열고 **런타임 → 모두 실행**을 누릅니다.
2. 첫 번째 파일 선택 창에서 **best.pt 하나**를 업로드합니다.
3. 두 번째 창에서 **영상 한 개 또는 여러 개**를 업로드합니다.
4. 자동 분석이 끝나면 **결과 영상과 이벤트 로그가 담긴 ZIP**이 다운로드됩니다.

## VLM 담당자에게

노트북의 **‘3. 팀의 기존 VLM 함수 연결’** 셀에 기존 VLM 호출 함수를 연결해 주세요. 위험 이벤트가 발생하면 **이벤트 정보, 현재 프레임, 최근 약 2초의 프레임 목록**이 자동으로 전달됩니다.

기존 임시 규칙 대신 이 노트북의 Trigger를 사용하면 됩니다. VLM 함수를 연결하기 전에도 검출·추적·Trigger와 결과 저장까지 실행할 수 있습니다. 기존 VLM·TTS 코드는 별도로 연결해야 합니다.
