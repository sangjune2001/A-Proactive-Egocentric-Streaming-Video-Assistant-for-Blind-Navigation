# 수정본 v5 (10/14) — 히트박스(B)만
# 놓친 장애물 (21초 상자, 27초 테이블)
- 원인: 검출 신뢰도 0.5 기준에서 아예 안 잡힘 (0.2~0.45)
- 히트박스용으로 신뢰도 0.2 검출을 따로 돌림
- 단, 0.5 미만은 내 진행 영역에 걸칠 때만 판정
- 태규 규칙(B0)은 원래 0.5 그대로
# 경고를 더 일찍
- 주의: 물체 히트박스가 내 진행 영역에 걸치면 바로
   (영역 길이 = 걸음 4초 앞 + 2 m)
- 위험: 정면(내 몸 ±0.6 m) + 2.5초 안 도달 (2 → 2.5초)
- 판정 시작 0.5 → 0.4초, 켜짐 지연 0.3 → 0.2초
- 영역 경계 0.2 m 걸쳐도 안으로 봄
- 물체 히트박스 옆 여유 1.0 → 0.4 m
   (내 영역 ±1.3 m에 이미 여유가 있어 두 번 세지 않게)
# 멀어지는 물체 제외
- 고정 화살표가 화면 위쪽(±50°)이면 경고 안 함
# 흔들림 보정 (영상은 그대로)
- 걸음마다 화면이 출렁인 양을 지평선에 반영
- 거리·미니맵·바닥 영역이 덜 흔들림
# 신호등
- off·차량 신호 표시 안 함, 확정된 색만 표시
- 확정: 새 색이 0.5초 이상 연속, 90% 이상 같은 색
   (분류 확률 0.8 이상만 셈)
- 알림: 이전 색이 보인 뒤 1.5초 안에 새 색이 확정될 때만
- 빛번짐으로 오래 안 보이다 바뀐 건 알림 안 함
# 범례
- 초록 안전 · 노랑 주의 · 빨강 위험
- 분홍 글씨 = 태규 규칙(B0)
- 색 타원 = 발에 붙인 히트박스, 흰 점선 = 시야각 투영
- 굵은 띠 = 경로, 화살표 = 1초 뒤 방향
- 하늘색 십자 = 걷는 방향·지평선
- 미니맵: 흰 원 = 나, 색 점 = 물체
- 카메라 높이 1.77 m (키 190 cm)
