# 수정본 v4 (10/14) — 히트박스(B)만
# 경고 놓침 줄이기
- 정지 물체도 내 걸음 속도로 다가오는 것으로 계산
- 도달 시간 = 거리 ÷ 다가오는 속도
- 주의: 영역 안 + 4초 안 도달 (또는 3초 히트박스 겹침)
- 위험: 정면(내 몸 ±0.6 m) + 2초 안 도달
   (또는 1.5초 히트박스가 내 몸과 겹침)
- 물체 폭을 미터로 반영 (넓은 물체 가장자리 기준)
- 영역 안 물체는 화면 TTC 조건 없이 판정
# 영역
- 옆 폭 ±1.05 → ±1.3 m
- 차도 인접(2초 안 차량)이면 길이 ×1.3, 폭 +0.3 m
- 화면 왼쪽 아래: 영역 계산 과정 + 위에서 본 지도
# 히트박스 위치 (둘 다 표시)
- 색 채운 타원 = 발에 붙인 바닥 히트박스
- 흰 가는 점선 타원 = 시야각 그대로 투영한 히트박스
- 흰 선 = 두 중심 차이 (길수록 거리 추정 오차 큼)
- 카메라 높이 1.70 → 1.77 m (촬영자 키 190 cm 눈높이)
# 신호등
- 신호등만 따로 검출 (1280 해상도, 3프레임마다)
- 신호 분류기로 빨강/초록/꺼짐/차량용 판정
- 영역과 상관없이 항상 표시
- 1.5초 다수결로 확정, 빨강↔초록 바뀌면 큰 배너
# 범례
- 초록 안전 · 노랑 주의 · 빨강 위험
- 분홍 글씨 = 태규 규칙(B0) 경고 (주의 노랑과 구분)
- 타원 = 물체 주변 1.5초 위험 범위 (옆 ±1.3 m, 진행 방향으로 늘어남)
- 굵은 색 띠 = 발 위치 경로, 화살표 = 고정된 1초 뒤 방향
- 하늘색 십자 = 걷는 방향(FOE)·지평선
- 미니맵: 흰 원 = 나, 색 점 = 물체
