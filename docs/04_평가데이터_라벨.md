## 2. VIABench 정답의 뜻 (원문)

- [ts, te] = **"모델이 해당 안내를 내야 하는 유효 시간 구간"**이다.
- 학생 14명이 150편을 시범 표기한 뒤, 전문 업체가 표기를 확장했다.
- **PDR:** 맞는 과제의 안내를 ts ≤ t ≤ te에 내면 탐지로 친다. **오탐은 감점하지 않는다.**

## 3. 그대로 쓰지 않는 이유와 재매핑

| 차이 | VIABench | 우리 (5주차 시나리오 4개) | 처리 |
|---|---|---|---|
| 옆 장애물 | "왼쪽에 가로수, 주의"를 **경고**로 봄 | 경로 옆 장애물 → **억제** | `suppress` 또는 중립 |
| 오탐 | 감점 없음 | 오탐/분이 핵심 지표 | 정답 밖 발화를 오탐으로 셈 |
| 범위 | 하위 과제 21개 | S1 이동체 · S2 장애물 · S3 신호 · S4 단차 | 범위 밖 과제는 중립 |
| 누락 | Vehicle 수직의 차량 횡단 없음 | 차량 횡단은 S1 억제 사례 | 우리가 추가 표기 |

**재매핑 규칙 (`labels_draft.py`)**

| VIABench 과제 | 우리 라벨 |
|---|---|
| Pedestrian Traffic Light | 색이 바뀌는 안내 → S3 경고 · 현재 상태 안내 → S3 중립 |
| Stairs / Staircase Up/Down | S4 경고 |
| Active Avoidance ("피해서 가라") | S2 경고 |
| Obstacle Alert | 움직이는 탈것 → S1 경고 · "옆에" → S2 중립 · 나머지 → S2 경고 · 보행자만 → 범위 밖 |
| 그 밖 (방향 이탈, 횡단보도, 표지판, 카메라 이상 …) | 범위 밖 (중립) |
